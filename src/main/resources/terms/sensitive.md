# 민감정보(정신건강 정보) 처리 동의

> 이 문서는 2026 간지톤 시연용 초안입니다. 실제 서비스 전에 법률 검토를 거쳐 다시 작성합니다.

「개인정보 보호법」 제23조에 따라 정신건강 정보는 다른 개인정보와 따로 동의를 받습니다.

## 1. 처리 항목
고민 글(인테이크), 상담 대화, 상담 전후 기분 점수, AI가 만든 상담 리포트, 위기 신호 기록

## 2. 처리 목적
- 나에게 맞는 상담사 추천
- 상담 진행과 상담 리포트 작성
- 자해·자살 위험 신호를 빨리 알아차리고 위기 연락처 안내
- 수련생 상담의 품질 관리 (전문가 슈퍼비전)

## 3. 안전하게 다루는 방법
- 모든 민감정보는 암호화해서 저장합니다.
- 상담 리포트는 내가 따로 동의한 전문가 1명에게만 전달되며, 언제든 철회할 수 있습니다.
- 운영자가 민감정보를 열람하면 사유와 함께 기록이 남습니다.

## 4. 국외 이전 (AI 분석)
| 항목 | 내용 |
| --- | --- |
| 이전받는 자 | LLM 공급사 (Upstage) |
| 이전 항목 | 고민 글·상담 대화 (이름·연락처 등은 보내기 전에 가립니다) |
| 시기·방법 | 분석이 필요할 때마다 암호화된 통신으로 전송 |
| 이용 목적 | 감정·주제 분석, 상담 리포트 작성, 위기 신호 판단 |
| 보유 기간 | 분석 직후 삭제 (공급사 정책에 따름) |

## 5. 보유 기간
탈퇴하면 30일 뒤 파기합니다.

## 6. 동의를 거부할 권리
동의를 거부할 수 있으나, 상담 서비스의 핵심 기능이라 거부하면 가입할 수 없습니다.
