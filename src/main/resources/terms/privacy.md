# 개인정보 수집·이용 동의

> 이 문서는 2026 간지톤 시연용 초안입니다. 실제 서비스 전에 법률 검토를 거쳐 다시 작성합니다.

## 1. 수집 항목과 목적

| 구분 | 항목 | 목적 |
| --- | --- | --- |
| 공통 | 이메일(로그인용, Firebase에만 저장), 닉네임 | 회원 식별, 로그인 |
| 수련생·전문가 | 실명, 소속, 자격 정보·서류 | 자격 심사, 정산 |
| 결제 시 | 이름, 생년월일, 휴대폰 번호 | 본인 확인, 결제·환불 |
| 자동 수집 | 접속 기록, 기기 알림 토큰 | 보안, 알림 발송 |

이메일과 실명은 상담 상대에게 공개되지 않습니다. 상담사에게는 닉네임만, 내담자에게는 상담사의 활동명만 보입니다.

## 2. 보유 기간
- 탈퇴하면 30일 뒤 지체 없이 파기합니다.
- 결제·환불 기록은 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 5년 보관합니다.
- 접속 기록은 「개인정보의 안전성 확보조치 기준」에 따라 2년 보관합니다.

## 3. 처리 위탁
| 수탁자 | 위탁 업무 |
| --- | --- |
| Amazon Web Services | 서버 운영, 데이터·파일 저장 |
| Google Firebase | 로그인, 알림 발송 |
| LLM 공급사 (Upstage) | AI 분석 (아래 민감정보 동의에 따름) |

## 4. 개인정보 보호책임자
MindCare 팀 백엔드 담당 (문의: 서비스 내 고객센터)

## 5. 동의를 거부할 권리
동의를 거부할 수 있으나, 필수 항목이라 거부하면 가입할 수 없습니다.
